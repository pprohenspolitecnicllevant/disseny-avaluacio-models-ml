1Fonaments

  • Aprenentatge automàticL'algorisme dedueix les regles a partir d'exemples (dades + respostes → regles), en lloc d'escriure-les nosaltres. El model només és tan bo com les dades que li donem. NB 1.1 · diapos UT1

  • Entrenar (aprendre)Buscar els valors dels paràmetres que fan l'error més petit: el fons de la «vall» de l'error. diapos UT1 · NB 2.1

  • HiperparàmetresLa configuració que triem nosaltres abans d'entrenar i que el model no toca mai: max_depth, test_size, el grau del polinomi. NB 1.2 · NB 2.3→ UT7

4Avaluar honestament

  • Entrenament i prova (train_test_split)Apartar dades abans d'entrenar, amb un test d'entre el 10% i el 30%. Avaluar amb dades vistes és corregir un examen a qui ha vist les respostes. NB 1.2→ UT7
  • Conjunt de validacióUn tros per comparar models i triar hiperparàmetres sense tocar el test (60/20/20). NB 2.2 · NB 2.3→ UT7
  • Test segellatEs reserva al principi i s'obre una sola vegada, a la UT10. Cada decisió presa mirant la validació la fa una mica optimista. NB 2.2 · NB 2.3→ UT10
  • Model de referència (DummyRegressor, DummyClassifier)Un model que no mira les dades: diu sempre la mitjana o la classe més freqüent. Un número tot sol no vol dir res fins que el compares. NB 1.2 · NB 2.1 · NB 2.2
  • Fuga d'informació (data leakage)El model veu informació que no tindria en predir: l'objectiu entre les entrades, o un transformador preparat amb dades de validació. NB 1.2 · NB 2.3→ UT7 · UT9

  • Mirar casos concretsUna taula real / predit / error ensenya el que la mitjana amaga. NB 1.2 · NB 2.1
  • Variabilitat de la mesuraAmb un test petit, canviar la llavor mou el R2. «El model no necessita més dades, la mesura sí.» NB 1.2→ UT7

  • Validació creuadaLa versió sòlida de partir les dades en entrenament i validació. NB 1.2 · NB 2.2→ UT7

5Regressió lineal i polinòmica

  • Regressió linealMultiplicar cada entrada per un número i sumar-ho tot. No sap fer corbes ni condicions. diapos UT2
  • Regressió lineal simpleUna entrada i una recta, definida pel pendent (quant puja per cada unitat) i l'ordenada a l'origen (el punt de partida). NB 2.1
  • Regressió lineal múltipleDiverses entrades, amb un coeficient per a cada variable. Ja no es pot dibuixar. NB 2.2
  • Llegir els coeficients«Per cada mil·límetre d'aleta, uns 50 grams més.» Amb diverses variables s'hi afegeix «si la resta no canvien», i no es poden comparar entre si. NB 1.2 · NB 2.1 · NB 2.2
  • Afegir variablesNomés ajuda si aporta informació nova que el model pugui aprofitar. Té costos: cal tenir-les totes per predir, el model s'explica pitjor i sobreajusta més fàcilment. NB 2.2 · NB 2.3
  • ExtrapolacióPredir fora del rang de les dades d'entrenament, on el model continua la recta i diu bestieses. NB 2.1 · NB 2.2
  • Regressió polinòmica (PolynomialFeatures)Fabricar columnes noves (x², x³…) perquè el mateix model lineal dibuixi corbes. El grau és un hiperparàmetre. NB 2.3
Vist de passada
  • Què minimitza fit()Els errors al quadrat, no el MAE. Per això la seva recta no és idèntica a la que trobem provant pendents a mà. NB 2.1
  • Ordenada sense sentit físicUn pingüí d'aleta zero pesaria −6 kg: és un ajust matemàtic, no una afirmació sobre pingüins. NB 1.2 · NB 2.1 · NB 2.2
  • Variables redundantsQuatre mides del districte que diuen el mateix es reparteixen el pes i donen coeficients absurds. NB 2.2→ UT3
  • Variables que només funcionen juntesLa latitud i la longitud: soles diuen poc; juntes diuen on és el districte. NB 2.2
  • InteraccionsAmb diverses entrades, PolynomialFeatures també les multiplica entre elles (tmax × cap_de_setmana). NB 2.3
  • Fabricar variables a màDonar al model la informació ja preparada, com la distància a la ciutat més propera. NB 2.2 · NB 2.3→ UT3
  • EscalatDividir la temperatura entre 30 perquè les potències no es disparin, i posar les variables a la mateixa escala per poder comparar coeficients. NB 1.2 · NB 2.2 · NB 2.3→ UT3
  • InterpretabilitatLa regressió lineal «s'explica sola»; els models més potents, no. NB 2.1→ UT5
  • Importància de variablesCom mesurar quina variable pesa més de veritat. NB 2.2→ UT5

6Mètriques de regressió

  • MAEDe mitjana, quant m'equivoco, en les unitats de la variable. Es pot explicar a qualsevol. NB 2.1
  • RMSEEleva els errors al quadrat abans de fer la mitjana i castiga els grans. Sempre surt igual o més gran que el MAE. NB 2.1
  • Desviació percentual (MAPE)L'error mitjà en percentatge, sense unitats. Es torna boja quan els valors reals són propers a zero. NB 2.1
  • R2La part de l'error de «dir sempre la mitjana» que ens estalviem. 1 és perfecte, 0 és com dir la mitjana i un valor negatiu és pitjor. És el que dona score() en regressió. NB 1.2 · NB 2.1
  • Triar la mètrica segons el problemaEl MAE si tots els errors costen igual; el RMSE si un error gran és molt pitjor que molts de petits (el veterinari). Mirar-ne sempre més d'una. NB 2.1 · NB 2.3
Vist de passada
  • Error d'una prediccióPredit menys real. El signe diu si el model es passa o es queda curt. NB 2.1
  • Quocient RMSE / MAECap a 1,2 o 1,3 és normal; 1,5 o més avisa d'uns quants errors enormes. NB 2.1
  • MAE estable i R2 enfonsatPocs errors catastròfics gairebé no mouen el MAE, però enfonsen el R2. NB 2.3
  • AccuracyEl percentatge d'encerts, que és el que dona score() en classificació. NB 1.2→ UT4

7Sobreajust

  • Infraajust (underfitting)El model és massa simple per a la forma de les dades i s'equivoca molt fins i tot amb l'entrenament. NB 2.3
  • Sobreajust (overfitting)El model memoritza l'entrenament, soroll inclòs, i falla amb dades noves. NB 2.3
  • Error d'entrenament contra error de validacióLa distància entre tots dos és el senyal d'alarma. L'error d'entrenament sempre prefereix el model més complex, i per això no serveix per triar. NB 2.2 · NB 2.3
  • Complexitat del model i quantitat de dadesEl sobreajust depèn de la relació entre totes dues. Es combat simplificant el model o aconseguint més dades. NB 2.3
Vist de passada
  • On comença el sobreajustAls llocs on hi ha poques dades, com els extrems de temperatura. NB 2.3
  • El mateix dilema en altres modelsLa profunditat de l'arbre, la C de les SVM i la cerca d'hiperparàmetres. NB 2.3→ UT5 · UT6 · UT7
